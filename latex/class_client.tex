\doxysubsection{Detailed Description}
Represents a standard library user with regular privileges. 

The \doxylink{class_client}{Client} class inherits from \doxylink{class_user}{User} and implements serialization which the \doxylink{class_admin}{Admin} class also inherits. Standard clients cannot add or remove users or books.
