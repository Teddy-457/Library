\doxysubsection{Detailed Description}
Represents a library user with administrator privileges. 

The \doxylink{class_admin}{Admin} class inherits from \doxylink{class_client}{Client} but initializes the user with elevated privileges ({\ttfamily \doxylink{class_user_ae083699174159738ee4095915d70bcaa}{m\+\_\+admin} = true}). Administrators have the authority to add or remove books and manage other users in the library system.
