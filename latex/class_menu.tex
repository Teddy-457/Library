\doxysubsection{Detailed Description}
A singleton class that manages the interactive command-\/line interface. 

The \doxylink{class_menu}{Menu} class handles reading user input from the standard input, parsing commands, gathering necessary arguments, and delegating execution to the \doxylink{class_library}{Library} instance.
